# Décisions d’architecture

Les Architecture Decision Records — ADR — consignent les décisions techniques qui imposent durablement une direction au projet.

## Convention

Un ADR contient au minimum : contexte, décision, conséquences et alternatives. Il n’est pas réécrit pour masquer l’historique. Lorsqu’une décision change, un nouvel ADR remplace explicitement l’ancien.

Statuts utilisés : `Proposé`, `Accepté`, `Refusé`, `Remplacé`.
